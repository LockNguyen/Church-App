## Codebase Patterns
- Flutter localization uses `flutter_localizations` SDK package (already configured in pubspec.yaml)
- Uses Clean Architecture: domain/entities, data/models, data/repositories, presentation
- Firebase Firestore for data, Firebase Storage for images
- l10n: ARB files in lib/l10n/, generated code in lib/l10n/generated/
- l10n: Run `flutter gen-l10n` after changing ARB files
